
CUSTOM-BLENDED FOUNDATION & CONCEALER
Project by Ricoz Innovations

PROJECT DESCRIPTION:
A web-based platform for customized foundation and concealer products based on individual skin tones.

TECHNOLOGIES:
- HTML
- CSS
- JavaScript

PROJECT FILES:
- index.html – Home page
- style.css – Website styling
- app.js – JavaScript functionality
- images/ – Website images

HOW TO RUN:
1. Open the project folder in VS Code.
2. Open index.html.
3. Right-click and select "Open with Live Server".
